# Operating the project

Use [EXECUTION_PLAN](EXECUTION_PLAN.md) to direct work and
[NEXT_SESSION](NEXT_SESSION.md) to see the current position.

Every update should answer four questions: what outcome now works, what evidence
proves it, what remains in the active unit, and what happens next. Test totals and
time spent are supporting information, not completion measures.

Joe supplies device actions, real exports, protected measurement decisions and
required production approvals. The implementation owner prepares concrete choices
and continues independent work while those inputs are pending.

Backend completion means accepted contracts, verified deployment and real operating
evidence. Future statistical discoveries are allowed to remain pending. The frontend
begins after the backend release gate; its display requirements must already be
represented in the backend responses.

Earlier versions of these instructions are retained under
`docs/history/2026-09-09-instruction-cleanup/` for audit only.
